# 阶段 1 · 机动性平衡模拟

> 目的：验证设计文档 §12 阶段 1 的验收标准「玩家速度优势可感知：能靠移动甩开追击」，
> 并给怪物密度、陷阱密度与卡片费用提供数据依据。

## 方法

- 用**正式规则层**（`rules/fog/scent.ts`、`rules/monsters/`、`rules/traps/`、`rules/dice/`）跑无头模拟，
  不另写一套近似逻辑，所以结论对游戏本身有效。
- 种子化：每个种子一局，200 局取平均，可复现（`npm run balance`）。
- 玩家三种策略：
  | 策略 | 行为 |
  |---|---|
  | `run` | 沿最短路直奔出口，遇怪就近战 |
  | `fight` | 怪物进入 2 格内时，额外花 6 移动点出一张卡 |
  | `escape` | 怪物进入 3 格内时原地静止 2 回合（触发追击降级），之后继续跑 |
- 关卡用 `generateValidLevel` 生成（BSP、34×24、7 房间），怪物用**关卡生成器自己的布点**：
  距起点 ≥ 8 格，比例 50% 嗅犬 / 20% 石卫 / 15% 游魂 / 15% 蛛巢。
- 陷阱按 §4.2 结算：5 点直接伤害 + 50% 流血（3 伤 × 3 回合）/ 50% 中毒（2 伤 × 3 回合），
  踩中即消耗。陷阱承伤计入总承伤。
- **局限**：模拟不使用卡牌效果与掉落（`fight` 策略只是固定花 6 点），
  因此本报告不衡量卡牌强度，也不反映击杀掉卡的滚雪球。

## 结论

1. **BSP 地图把「怪物威胁」换成了「陷阱威胁」。** 到出口率 97% 远高于 §15 的 60% 下限，
   但平均承伤 29.0 仍落在 20–60 的目标带内；其中 **15.4 来自陷阱**，怪物只贡献约一半。
   0 怪局仍有 15.1 承伤，说明陷阱已经是独立且可感知的威胁。

2. **陷阱密度是当前最敏感的旋钮。** 平均每局踩中 1.6 个陷阱、承伤 15.4，
   若后续觉得「跑图太痛」，优先调 `trapDensity`（当前 0.06），而不是继续加怪物。

3. **逃脱机制仍然有效。** `escape` 的甩开率 87%，代价是多花 3.8 回合、多承伤 9.6。
   它适合被贴身锁定时的翻盘，但不是最优路线——这符合「危险但可解」的设计目标。

4. **「遇怪就打」不再是死策略。** 旧地图上 fight 只有 48% 到出口率，BSP 后是 92%：
   地图更大、房间更多，遭遇战很少正好压在唯一通路上。但打怪仍要花移动点，
   卡牌价值应继续落在「用点数换效率」上（远程 / 控制），而不是站着互砍。

5. **怪物密度在 6 只以上饱和。** 因为布点预算固定为 8，扫描超过 8 不再变化；
   真正影响威胁的是怪物组合与陷阱密度。

6. **死路统计为 0。** BSP + 房间内墙增广后没有出现度数 1 的格子；
   本轮只记录、不设上限（零死路属阶段 2 的验收项）。

## 建议参数（阶段 1）

| 参数 | 文档原值 | 建议 | 理由 |
|---|---|---|---|
| `monsterBudget` | 14 | **8**（已改到代码里） | 6 只以上饱和；当前到出口率 97%、承伤 29.0 |
| `trapDensity` | 未定 | **0.06**（已改到代码里） | 平均 1.6 次触发 / 15.4 承伤，约占全部承伤的一半 |
| 玩家 HP | 100 | 保持 | 承伤 29–39 时失败率低，符合 §15 的完成率目标 |
| 怪物初始组合 | 未定 | 50% 嗅犬 / 20% 石卫 / 15% 游魂 / 15% 蛛巢 | 速度、血量、穿墙、布陷阱四种威胁，混编才有「绕谁」的决策 |
| §14 验证项 | 只有承伤上限 | **补一条下界：平均承伤 < 20 → 威胁不足** | 避免重演「怪物是装饰品」 |

## 待钉死的规则歧义

「进入怪物所在格视为近战攻击」在文档里没有细则，阶段 1 必须先定，否则实现会分叉。
本模拟采用的假设（需要确认）：

- 近战消耗 **1 移动点**，造成 **5 点伤害**（玩家基础攻击力）；
- 怪物没死时玩家**停在原地**（无法穿过怪物）；
- 每次近战都会吃到该怪物当回合的攻击。

```bash
npm run balance
```
