# 《迷雾迷径》产品规划文档

> 回合制 · 六边形网格迷宫探索 Roguelite
> 版本 v1.1 · 2026-11-04 · 状态：设计已确认，待实现计划

---

## 1. 概述

### 1.1 一句话定位

在一座完全漆黑、由墙体构成的迷宫里，你靠掷骰获取行动力、靠卡牌战斗与自保、靠气味判断怪物是否逼近，穿过奇遇与陷阱，击败守卫抵达对侧出口。

### 1.2 核心体验支柱

| 支柱 | 含义 | 支撑机制 |
|---|---|---|
| **黑暗中的推理** | 看不见，所以必须靠探听与记忆规划 | 纯黑迷雾 + 探听三态反馈 |
| **骰子的赌博** | 每回合的点数决定你这回合是爆发还是苟活 | 3d6 锁骰分配 |
| **嗅觉的追逐** | 怪物不是雷达，它循着你留下的气味走 | 气味场 + 三态追踪 |
| **资源紧张** | 你的卡是消耗品，打一张少一张 | 卡牌消耗品经济 + 奇遇补给 |

### 1.3 平台与技术形态

- **平台**：Web 浏览器优先（桌面端优先，兼顾移动窄屏）
- **前端**：React 18 + TypeScript + Canvas 2D + Zustand
- **后端**：轻量 Serverless 代理，仅用于转发 LLM 出题请求与隐藏 API Key
- **单局时长**：20–30 分钟
- **一局规模**：约 400–600 格的大型迷宫，10 张起始卡

## 2. 核心循环

```
┌──────────────────────────────────────────────────────┐
│  局外：解锁卡池 · 扩充起始牌数 · 调整起始配置          │
└───────────────────────────┬──────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────┐
│  局内：选 10 张牌 → 进入迷宫                          │
│                                                      │
│   ┌── 玩家回合 ─────────────────────────────┐       │
│   │ 掷 3d6 → 行动                            │       │
│   │  ├ 移动（消耗移动点）                    │       │
│   │  ├ 探听（消耗移动点，每回合限 2 次）      │       │
│   │  ├ 出牌（投入骰子）                      │       │
│   │  └ 结束回合                              │       │
│   └───────────────┬──────────────────────────┘       │
│                   ↓                                   │
│   ┌── 结算 ─────────────────────────────────┐       │
│   │ 气味更新 → 怪物行动（各掷 1d6）→ 感知更新  │       │
│   └───────────────┬──────────────────────────┘       │
│                   ↺ 回到玩家回合                       │
│                                                      │
│   途中：奇遇房 · 宝箱房 · 祭坛 · 商店 · 陷阱 · 战斗     │
└───────────────────────────┬──────────────────────────┘
                            ↓
                 击败出口守卫 → 抵达出口 → 胜利
```

## 3. 回合结构与骰子经济

### 3.1 回合流程

**玩家回合开始**
1. 递减 buff 时长（免伤类 buff 在本回合结束时才失效，保证覆盖完整回合）
2. 刷新怪物意图显示（图标 + 数字）
3. 掷 3 颗 d6

**行动阶段**（顺序自由，可反复进行，直到无合法行动或主动结束）

| 行动 | 消耗 | 说明 |
|---|---|---|
| 移动 1 格 | 1 移动点 | 沿相邻格移动；进入怪物所在格视为近战攻击 |
| 探听 | 1 移动点 | 每回合限 2 次（可被卡牌提升） |
| 打出卡牌 | 投入一颗骰子 | 骰子不可拆分 |
| 结束回合 | — | 快捷键 `空格` |

**玩家回合结束**
1. 气味更新：玩家本回合走过的每格 +1
2. 怪物行动：每只怪物各掷 1d6，得到本回合移动步数，按其状态行动
3. 怪物感知更新：采样气味场，决定 `游荡 / 警觉 / 追击`
4. 全图气味 -1（下限 0）

### 3.2 锁骰规则

| 规则 | 定义 |
|---|---|
| 投掷 | 每回合固定 3 颗 d6，不主动重掷（卡牌可提供重掷） |
| 投入卡牌 | 骰子**不可拆分**，一张 `cost` 的卡需要一颗 `骰面 ≥ cost` 的骰子 |
| 一对一 | 一颗骰子只能投入一张卡 |
| 移动点 | **未投入卡牌的骰子，其面值的总和** = 可移动格数（1 点 = 1 格） |
| 卡牌点数 | 卡牌 `cost` 范围 1–4 |

**示例**：掷出 5 / 4 / 1
- 方案 A：5 点骰 → cost 5 卡，4 点骰 → cost 4 卡，1 点骰 → 移动 1 格
- 方案 B：5 点骰 → cost 3 卡（浪费 2 点），其余 4+1 = 5 点移动
- 方案 C：三张卡（5→cost5，4→cost4，1→cost1），0 移动点，本回合完全放弃机动

> 设计意图：同一手骰子在不同分配下产出完全不同的回合，"点数决定行动力"因此包含**火力与机动的取舍**，而非单纯的总量换算。

### 3.3 速度平衡

| 角色 | 每回合移动期望 | 说明 |
|---|---|---|
| 玩家 | 3–6 格（实际） | 骰子总和期望 10.5，但多数骰子会被卡牌消耗 |
| 嗅犬 / 游魂 / 守卫 | 3.5 格 | 掷 1d6 作为步数 |
| 石卫 | 2 格 | 固定 1–3 步，移动慢 |
| 蛛巢 | 0 格 | 静止，以陷阱代替移动 |

玩家机动性约为游荡怪物的 1.5–2 倍，**足以周旋但没有余裕**。这是"能甩开但甩不掉"的基准手感。

## 4. 资源系统

| 资源 | 初始/上限 | 获取 | 消耗 |
|---|---|---|---|
| HP | 100 | 恢复类卡牌、休整房 | 受击、陷阱、答错惩罚 |
| 卡牌 | 10 张（可局外扩至 15） | 奇遇房、宝箱房、战斗掉落、商店 | 打出即消失（消耗品） |
| 行动点 | 每回合由骰子产生 | 掷骰 | 移动、探听、卡牌 |
| Buff | 带回合时限 | 卡牌、祭坛、奇遇房 | 时限到自动失效 |
| 气味 | 地图字段（玩家不直接可见） | 移动 | 每回合自然衰减，可被地形清除 |
| 碎片 | 0 | 击败怪物、奇遇房答对 | 商店买卡 / 升级 / 治疗 / 提示 |

> **MVP 范围**：碎片、商店、祭坛在阶段 3 之后实现。阶段 0–2 的唯一资源是卡牌 + HP。

### 4.1 状态效果

负面状态由陷阱房施加，可被「止血」卡清除。

| 状态 | 效果 | 持续 |
|---|---|---|
| 流血 | 每回合结束扣 3 HP | 3 回合 |
| 中毒 | 每回合结束扣 2 HP，且治疗效果减半 | 3 回合 |

Buff 与状态统一由 buff 生命周期模块管理（施加时记录剩余回合，回合结束递减，归零移除）。

## 5. 迷雾、探听与气味

### 5.1 迷雾规则

- **未踏足的格子完全不可见**（纯黑，连墙体结构都不显示）
- 踏足过的格子**永久可见**（已探索区域常驻显示）
- 奇遇房门**自发光**：即使在纯黑迷雾中也保留一点微弱冷光，作为"附近有东西"的唯一视觉暗示

### 5.2 探听机制

玩家在完全黑暗的迷宫里必须有主动获取信息的手段，否则导航退化为撞墙试错。

| 项 | 规则 |
|---|---|
| 成本 | 1 移动点 |
| 频次 | 每回合限 2 次（`探查术` 卡可临时 +3） |
| 范围 | 玩家所在格的**所有相邻格** |
| 返回 | 每个未踏足相邻格返回三态之一 |

**探听三态**

| 返回 | 含义 |
|---|---|
| `有墙` | 该方向不可通行 |
| `通路（安静）` | 可通行，且无异常 |
| `通路（有异响）` | 可通行，但内含陷阱 |

> 陷阱因此是**公平但需推理**的：你知道"那边有东西"，但不知道是什么、要不要赌。

### 5.3 气味规则

| 规则 | 定义 |
|---|---|
| 产生 | 玩家每移动 1 格，在**途经的每一格（含落点）**留下气味 +1 |
| 衰减 | 每回合结束全图 -1，下限 0 |
| 静止 | 玩家不动 → 该格气味不增长，但也不会立即消散（需等自然衰减） |
| 清除 | 特殊地形（下回合踩上时）把该格及相邻格气味归零 |

**特殊地形**：乱石堆、水渍、通风口。三类效果统一为"清除周围气味"，视觉上通过贴图区分。

### 5.4 感知判定

```
警觉：怪物的【感知半径】内，存在气味 ≥ 2 的格
      → 怪物获得玩家「最后已知位置」（该范围内气味最高的格），进入警觉

追击：怪物与玩家的距离 ≤ 2
      → 锁定玩家实时位置，进入追击
```

> 感知半径是"闻得到多远"，因此不同怪物对同一片气味有不同反应：石卫（半径 2）迟钝、游魂（半径 4）灵敏。距离与气味是两个独立维度，二者取交集才触发警觉。

## 6. 怪物系统

### 6.1 三态追踪

| 状态 | 行为 | 计入眼睛徽章 |
|---|---|---|
| **游荡** | 随机移动（走向随机可达格） | 否 |
| **警觉** | 朝气味最高的方向寻路；到达后原地搜索相邻几格 | 是 |
| **追击** | 锁定玩家实时位置，直线扑杀，每回合 1–6 步 | 是 |

### 6.2 追击解除条件（任一满足）

0. **预警**：怪物首次从游荡/警觉转入追击时，先预告 1 回合（显示"它发现你了"），该回合不移动不攻击 —— 玩家有一次反应窗口
1. 玩家进入**低气味区**（相邻格气味均 ≤ 1）并**静止 2 个回合** → 追击降级为警觉
2. 命中「驱散 / 致盲」类卡牌 → 直接降级为游荡
3. 命中「定身」卡牌 → 本回合无法行动与感知（不改变状态，但打断锁定）

> 三条解除路径保证"被锁定"是**危险但可解**的，而不是必死。缺乏解除手段的追击只会制造死亡螺旋。

### 6.3 意图显示

右上角**眼睛图标 + 角标**显示处于 `警觉 / 追击` 的怪物数量。悬停展开每只怪物的状态、意图与距离。

怪物格上方显示意图图标与数字：

| 意图 | 含义 |
|---|---|
| 👣 + N | 移动 N 格 |
| ⚔ + N | 攻击，伤害 N |
| 🔍 | 搜索 |
| ❄ | 被定身 |

玩家格周围显示攻击范围高亮。

### 6.4 怪物原型

| 怪物 | HP | 伤害 | 感知半径 | 移动 | 特点 |
|---|---|---|---|---|---|
| 嗅犬 | 20 | 4 | 3 | 1d6 | 快、追击积极，主要威胁 |
| 石卫 | 60 | 10 | 2 | 1–3 | 慢、高伤高血，适合教学 |
| 游魂 | 25 | 6 | 4 | 1d6 | **无视墙体移动**，压迫感来源，HP 低 |
| 蛛巢 | 30 | 3 | 2 | 静止 | 在周围布陷阱，考验路线规划 |
| **守卫（Boss）** | 200 | 12 | 全图 | 1d6 | 守在出口，三阶段 |

**守卫三阶段**
1. 冲击：每回合冲向玩家并重击
2. 召唤：召唤 2 只嗅犬，自身回血
3. 爆发：范围 AOE，需靠移动与卡牌规避

### 6.5 战斗结算

```
最终伤害 = max(1, 卡牌伤害 - 目标防御值 - 目标减伤buff值)
```

- **玩家基础攻击力 = 5**（不依赖卡牌）。卡牌打空时仍可徒手攻击，这是没有资源时的兜底手段
- 玩家受击扣除 HP；HP ≤ 0 → 本局失败
- 防御类卡牌提供回合制减伤；`闪避` 可完全免伤一次
- 进入怪物所在格视为近战攻击（伤害 = 玩家基础攻击力 5）

## 7. 卡牌系统

### 7.1 通用结构

```
{ id, name, type, rarity, cost, effect, upgradeable }
```

- `type`：攻击 / 防御 / 恢复 / Buff / 功能
- `rarity`：普通 / 精良 / 史诗
- `cost`：1–4
- 卡牌是**消耗品**，打出即从牌库移除

### 7.2 初始卡池（普通）

| 名称 | 类型 | cost | 效果 |
|---|---|---|---|
| 挥击 | 攻击 | 1 | 造成 6 伤害 |
| 投石 | 攻击 | 2 | 造成 8 伤害（远程直线） |
| 重锤 | 攻击 | 3 | 造成 14 伤害，击退 1 格 |
| 铁壁 | 防御 | 2 | 本回合受到伤害 -4 |
| 闪避 | 防御 | 1 | 本回合首次受击完全免伤 |
| 药剂 | 恢复 | 2 | 回复 20 HP |
| 止血 | 恢复 | 1 | 移除流血 / 中毒 |
| 战意 | Buff | 2 | 接下来 3 回合伤害 +2 |
| 铁壁姿态 | Buff | 1 | 接下来 2 回合免疫伤害 |
| 疾行 | Buff | 1 | 接下来 2 回合额外移动点 +1 |
| 屏息 | 功能 | 2 | 清除相邻格气味，强制身边怪物降级为警觉 |
| 驱散 | 功能 | 3 | 指定怪物降级为游荡（打断追击） |
| 定身 | 功能 | 2 | 指定怪物本回合无法行动 |
| 探查术 | 功能 | 1 | 本回合探听次数 +3 |
| 换骰 | 功能 | 1 | 弃掉 1 颗骰子并重掷 |

### 7.3 精良 / 史诗牌池

| 名称 | 稀有度 | 类型 | cost | 效果 |
|---|---|---|---|---|
| 破甲 | 精良 | 攻击 | 2 | 造成 10 伤害，无视 3 点防御 |
| 荆棘甲 | 精良 | 防御 | 2 | 本回合受到伤害 -4，且反弹 3 伤害 |
| 应急 | 精良 | 恢复 | 1 | 回复 8 HP，本回合结束再回复 8 |
| 战吼 | 精良 | Buff | 3 | 接下来 3 回合伤害 +3，行动点 +1 |
| 猎手直觉 | 精良 | 功能 | 2 | 揭示周围 2 格内所有怪物位置 |
| 处刑 | 史诗 | 攻击 | 4 | 造成 22 伤害；若目标 HP < 30% 则伤害翻倍 |
| 静滞力场 | 史诗 | 功能 | 3 | 半径 2 内所有怪物本回合无法移动与感知 |
| 循环 | 史诗 | 功能 | 2 | 回收 1 张已打出的卡到牌库 |
| 血契 | 史诗 | Buff | 3 | 接下来 4 回合伤害 +4，每回合流失 3 HP |

### 7.4 卡牌升级（祭坛 / 奇遇房）

升级 = 为一张卡附加一个 modifier。**同类 modifier 不可叠加**，不同类可叠加。

| modifier | 效果 |
|---|---|
| 精简 | `cost` -1 |
| 锋利 | 伤害 +2 |
| 广域 | 范围 +1 格 |
| 强化 | 数值类效果 +50%（向下取整） |
| 专精 | 附加专属效果（逐卡定义，例：`药剂` 改为同时清除 1 层负面状态） |

### 7.5 平衡约束

强力"破局卡"（驱散 / 定身 / 击退 / 静滞力场）受**双重约束**：消耗品数量有限 + 需要占用骰子点数。因此不会出现"永远有解"，但被锁定时确有翻盘手段。

## 8. 房间与奇遇

### 8.1 房间类型

| 房间 | 进入时 | 产出 |
|---|---|---|
| 战斗房 | 强制遭遇 | 击败后掉随机卡（阶段 3 起额外掉碎片） |
| 陷阱房 | 踩到陷阱格 | 伤害 / 流血 / 中毒 / 召怪 |
| 宝箱房 | 交互 | 1 张卡 或 1 个 buff |
| 祭坛 | 交互 | 升级 1 张卡 |
| **奇遇房（Q&A）** | 交互 | 见 8.2 |
| 商店 | 交互 | 碎片换卡 / 治疗 |
| 休整房 | 交互 | 回血 + 锁定 1 张卡（防止之后被扣） |
| 出口房 | 守卫 | 胜利 |

> **可发现性补丁**：奇遇房门**自发光**（纯黑迷雾中留微弱冷光）；普通房间门不发光。奇遇因此是"黑暗迷宫里稀缺的一点光"，每次发现都有分量。陷阱房本身不发光，但其内部陷阱格通过探听返回"有异响"来预警，保证公平。

### 8.2 奇遇房（Q&A）流程

```
进入 → 请求题目（loading）→ 题目 + [对] [错] 按钮 + 可选 [提示]
                                        ↓
        答对 → 随机正面奖励：卡牌 / 回血 / 临时 buff（阶段 3 起追加碎片）
        答错 → 随机惩罚：损失 15% 最大 HP  或  随机失去 1 张卡（牌数保留下限 3）
```

| 规则 | 定义 |
|---|---|
| 题目 | 二选一（对 / 错）的事实性问题，中文 |
| 提示 | 消耗 1 张卡 → 排除一个选项，不直接给答案。阶段 3 引入碎片后，可改为花 1 碎片 |
| 连答 | 连续答对 3 题 → 额外奖励 1 张精良及以上卡牌 |
| 惩罚随机 | 答错时在「扣血」与「扣卡」之间随机二选一，避免玩家被单一惩罚卡死 |

### 8.3 LLM 出题链路

**请求 → 校验 → 重试 → 兜底**

```
客户端 → POST /api/question { difficulty, topic, seed }
            ↓
        服务端构造 prompt（含出题硬约束）
            ↓
        调用 LLM，要求严格 JSON 输出
            ↓
        JSON Schema 校验
        ├─ 通过 → 返回题目
        └─ 失败 → 重试（最多 2 次）
              └─ 仍失败 → 降级到内置题库（服务端静态题库，按难度分级）
```

**出题 prompt 硬约束**
- 单一确定答案，不存在歧义或多解
- 常识或已公开知识可验证
- 不涉及争议话题、时效性事实、具体日期 / 版本号 / 人名
- 中文表述，长度 ≤ 60 字
- 不给出"以下哪个"式的多选题

**题目 schema**

```json
{
  "question": "地球围绕什么公转？",
  "answer": true,
  "difficulty": "easy",
  "topic": "天文"
}
```

**降级策略**：LLM 超时（8s）/ 校验失败 / 服务不可用 → 立即使用内置题库，保证玩家永远不卡在 loading。

## 9. 关卡生成

### 9.1 生成流程

```
1. BSP 划分      → 6–9 个不规则房间区域
2. 走廊生成      → 生成树保证全连通
3. 墙增广        → 在房间区域内挖出迷宫结构
4. 造环          → 随机移除约 18% 的墙，形成环路
5. 校验          → 连通性 / 无孤岛 / 入口→出口路径长度 ≥ 20 格
                  / 奇遇房不贴门 / 陷阱不堵唯一通路
6. 布点          → 出口在入口对边；守卫守出口
                    怪物按难度分布（距入口 ≥ 8 格）
                    奇遇房 ≥ 2（分散不同象限）、商店 1、祭坛 1–2
                    陷阱按密度随机
```

### 9.2 关键约束

| 约束 | 原因 |
|---|---|
| 迷宫必须**有环** | 纯树状迷宫只有唯一解，玩家无"绕路"策略可言 |
| 出口在入口**对边** | 保证单局路径长度与 20–30 分钟时长 |
| 怪物距入口 ≥ 8 格 | 开局安全期，让玩家先熟悉探听与骰子 |
| 陷阱不堵唯一通路 | 避免出现必死格 |
| 奇遇房 ≥ 2 且分散 | 保证 Q&A 是核心体验而非可选项 |
| 种子化 RNG | 同 seed 完全可复现 → 便于测试、分享挑战、定位 bug |

### 9.3 难度参数

```ts
interface Difficulty {
  mazeWidth: number;      // 默认 34
  mazeHeight: number;     // 默认 24
  roomCount: number;      // 默认 7
  monsterBudget: number;  // 默认 14
  trapDensity: number;    // 默认 0.06
  guardianTier: number;   // 守卫强度档位
}
```

- **右上**：眼睛图标 + 角标（警觉/追击怪物数）、HP 条、回合数；碎片数从阶段 3 起显示

### 10.2 关键交互

| 交互 | 行为 |
|---|---|
| 锁骰 | 点卡牌 → 可用骰子亮起 → 点骰子打出；cost 不足的卡置灰并标注所需点数 |
| 意图 | 怪物格上方显示意图图标 + 数字；玩家格周围高亮攻击范围 |
| 气味残痕 | 已探索区域叠加热扰动纹理（线索而非精确数据） |
| 迷雾 | 未探索格纯黑；奇遇房门在黑幕上留冷光微芒 |
| 快捷键 | `空格` 结束回合 · `Esc` 取消骰子分配 · `1/2/3` 选骰子 · `Q` 探听 |

### 10.3 可用性要求

- 色盲友好：图标 + 颜色**双编码**，不依赖单一色相传达状态
- 字号可调（不小于 14px）
- 所有关键状态有文字标签，不只有图标
- 触屏可玩：骰子与卡牌支持点按操作，棋盘支持单指拖动

## 11. 技术架构

### 11.1 目录结构

```
src/
  rules/                纯 TS，零 DOM 依赖，可注入 RNG
    grid/               六边形格几何 · 六向邻接 · 边几何 · A* 寻路 · 视线
    dice/               骰子投掷与锁骰分配
    cards/              卡牌效果执行 · 升级 modifier
    combat/             伤害与防御结算
    buffs/              buff 生命周期
    monsters/           三态状态机 · 气味感知 · 意图生成
    fog/                迷雾可见性 · 探听 · 气味场
    turn/               回合状态机（纯 reducer）
    generation/         关卡生成与校验
    content/            卡牌 / 怪物 / 房间数据表
  state/                Zustand store（只调用 rules 层纯函数）
  render/               Canvas 渲染器（棋盘 · 迷雾 · 单位 · 特效）
  ui/                   React 组件（HUD · 手牌 · 模态 · 标题画面）
  llm/                  题目客户端（含降级与缓存）
server/
  api/question.ts       LLM 代理（Schema 校验 · 重试 · 题库兜底 · 缓存）
  content/questions.ts  内置兜底题库（按难度分级）
shared/                 前后端共享类型（题目 schema · 错误码）
```

### 11.2 架构铁律

1. `rules/` 全部为**纯函数**且可注入 RNG → 可单测、可回放、可复现
2. `render/` **只读** state，不含任何规则判断
3. `ui/` 只向 store 派发**意图（intent）**，不直接修改状态
4. 规则层不依赖 React / DOM / 网络，可独立在 Node 下运行

### 11.3 状态流

```
UI 事件 → dispatch(intent) → store 调 rules 纯函数 → 新 state
                                                     ↓
                                            render 层重绘（rAF 合并）
```

### 11.4 测试策略

| 层级 | 工具 | 覆盖内容 |
|---|---|---|
| 规则单测 | Vitest | 骰子分配、伤害结算、气味衰减、感知状态迁移、buff 时序、生成器连通性 |
| 回放测试 | Vitest | `(seed, 操作序列)` → 状态快照断言，捕捉隐式回归 |
| 组件测试 | Vitest + Testing Library | HUD、锁骰交互、模态流程 |
| E2E | Playwright | 开局 → 探听 → 移动 → 奇遇房（mock LLM）→ 击败守卫 → 胜利 |
| 代理单测 | Vitest | Schema 校验失败重试、超时降级题库、缓存命中 |

### 11.5 持久化

| 数据 | 存储 | 说明 |
|---|---|---|
| 局外进度 | localStorage | 已解锁卡池、起始牌数、最高纪录 |
| 设置 | localStorage | 字号、音量、LLM 题目开关 |
| 局内快照 | localStorage（可选） | 支持中途退出续玩，作为增强项 |
| 统计数据 | localStorage + 后端（可选） | 迷路时长、死亡点、卡牌使用分布，用于平衡调参 |

## 12. 阶段规划

> 按**阶段**划分，不设时间上限。每个阶段有明确的验收标准，未通过则不进入下一阶段。

### 阶段 0 · 可玩骨架

**目标**：能在一座纯黑迷宫里，靠探听找到出口。

**范围**
- 六边形格渲染、墙以边线呈现、可落脚邻居高亮、缩放与拖动
- 迷雾：未踏足纯黑、踏足永久可见
- 探听三态反馈、回合与骰子、锁骰、移动
- 关卡生成器（MVP 尺寸：直线路径 + 少量支路）

**验收**
- [ ] 玩家能在无任何可见信息下，借助探听规划路线抵达出口
- [ ] 探听结果与实际地形 100% 一致（规则层单测覆盖）
- [ ] 骰子分配的每种组合都可通过 UI 完成且无非法状态

**可延后**：特效、动画、音效、局外系统

#### 视觉规格（v1.1 渲染改版）

| 元素 | 规格 |
|---|---|
| 地板 | 满铺正六边形（pointy-top），与轴向网格同构，相邻格共享整条边 |
| 墙 | **不占整格**，画在地板格与墙格共享的那条边上：实心粗线 + 内侧向内的渐变阴影；墙格本身保持纯黑 |
| 可落脚高亮 | 玩家周围「已知可站立」（已踏足 或 探听到是通路）的邻居用亮色描边 + 中心点标出，并在与玩家格共享的边上画一个指向邻居的箭头 |
| 未知区域 | 完全不绘制；未知邻居不会被高亮，不泄露任何信息 |

> **取舍记录**：墙线对可见地板格一律按真实地形绘制，玩家因此能直接读出已探索区的邻接关系，
> 探听的信息价值下降，只保留「通路 / 异响」与「标记可落脚」的增量。
> 后续阶段用异响、陷阱预警承担信息增量；若要收回该取舍，把渲染模型里墙边的取值
> 改为「仅当邻格已知为墙」即可，不影响其余渲染逻辑。

---

### 阶段 1 · 战斗与威胁

**目标**：一次完整的遭遇战有真实博弈。

**范围**
- 卡牌系统（普通卡池）、伤害与防御结算、buff 生命周期
- 4 种普通怪物 + 三态追踪 + 气味场
- 意图显示、眼睛徽章、气味残痕
- 追击三条解除路径（静止降级 / 驱散 / 定身）

**验收**
- [ ] 4 种怪物行为符合 6.4 表格，且追击可被三种方式分别解除
- [ ] 玩家速度优势可感知：能靠移动甩开追击
- [ ] 意图显示准确预告怪物下一步（伤害与距离）
- [ ] 规则层单测覆盖全部伤害与状态迁移分支

**可延后**：史诗卡、卡牌升级、碎片货币

---

### 阶段 2 · 内容与奇遇

**目标**：能完整通关一局，20–30 分钟，有起承转合。

**范围**
- 房间系统：战斗房 / 陷阱房 / 宝箱房 / 奇遇房 / 休整房 / 出口房
- 奇遇房 Q&A 全链路：后端代理、Schema 校验、重试、题库兜底、提示机制、连答奖励
- 守卫 Boss 三阶段
- 特殊地形（乱石 / 水渍 / 风口）与气味清除
- 完整尺寸关卡生成（造环、校验、布点）

**验收**
- [ ] LLM 不可用时，Q&A 房能在 1 秒内用题库出题，玩法不中断
- [ ] 题目 Schema 校验失败能被正确拦截并重试
- [ ] 一局完整通关耗时落在 20–30 分钟区间
- [ ] 关卡生成器对 1000 个随机 seed 均通过连通性与无死路校验

**可延后**：商店、祭坛升级、碎片经济

---

### 阶段 3 · 局外循环

**目标**：有理由玩第二局、第三局。

**范围**
- 卡池解锁、起始牌数扩容（10 → 15）
- 局内资源：碎片、商店、祭坛升级
- 存档（解锁进度 / 设置 / 局内快照）
- 标题画面、结算画面、统计埋点

**验收**
- [ ] 重开一局保留全部解锁进度
- [ ] 每局之间的差异可感知（牌组不同 / 起始配置不同）
- [ ] 埋点可导出用于平衡分析

---

### 阶段 4 · 打磨与发布

**目标**：可交给陌生玩家的成品。

**范围**
- 数值平衡调优（基于埋点数据）
- UI 动效、音效、粒子表现
- 新手引导（首局分步引导，解释探听与锁骰）
- 性能优化（网格重绘、迷雾缓存）
- 移动窄屏适配、响应式
- 部署（静态前端 + Serverless 代理）

**验收**
- [ ] 首次游玩者在 5 分钟内理解核心循环（无引导下测试 5 人样本）
- [ ] 首局完成率 ≥ 60%
- [ ] 中端设备下渲染稳定 60fps
- [ ] 移动端窄屏可完整游玩

## 13. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 完全黑地图导致挫败 | 玩家早期流失 | 探听 + 三态提示 + 奇遇门冷光 + 陷阱异响预警 + 阶段 4 新手引导 |
| 墙线按真实地形绘制导致探听贬值 | 玩家不再需要探听即可读出邻接关系，「黑暗中的推理」被削弱 | 已确认接受：探听聚焦「通路 / 异响」与可落脚标记；阶段 1 起由异响与陷阱预警承担信息增量 |
| LLM 出题质量不稳定 / 延迟高 / 失败 | Q&A 房体验断裂 | Schema 校验 + 重试 + 题库兜底 + 8s 超时降级 + 难度分级 |
| 追击锁死形成死亡螺旋 | 玩家无解感 | 玩家机动 ×1.5–2 + 静止降级 + 破局卡 + 追击首次触发有 1 回合预警 |
| 探索感与可解性失衡 | 迷宮变成枯燥的撞墙 | 埋点分析迷路时长与死亡点，参数化调探听成本与雾气衰减 |
| 资源过紧导致中后期无牌可用 | 战斗退化为纯走位 | 奇遇房 ≥ 2 + 宝箱补给 + 商店补货；监测"回合末牌数"分布 |
| 单局时长偏离目标 | 影响留存 | 生成参数化难度 + 埋点统计实际时长，反向调 `mazeWidth` / 怪物预算 |
| Web 优先但 LLM 需服务端 | 部署复杂度 | 仅一个 Serverless 端点；前端对题目接口做适配层，将来可换供应商 |

## 14. 待验证项（已有默认策略，按数据调整）

| 项 | 默认值 | 验证方式 | 调整触发条件 |
|---|---|---|---|
| 骰子数量 | 3 颗 d6 | 埋点统计每回合卡牌打出数 | 若平均打出 > 2.5 张卡 → 骰子不足，考虑 4 颗 |
| 探听频次上限 | 2 次/回合 | 统计每回合探听次数 | 若平均 < 0.5 次 → 成本过高，放宽为 3 |
| 玩家 HP | 100 | 统计平均承伤与死亡点 | 若平均承伤 > 60 → HP 偏高或怪物伤害偏高 |
| 追击脱离静止回合数 | 2 回合 | 统计追击成功率与脱离成功率 | 若脱离率 > 70% → 惩罚过轻 |
| 特殊地形密度 | 每 80 格 1 个 | 统计玩家踩中率 | 若极少被使用 → 提示不足，增加视觉引导 |
| 怪物数量 | 14 | 统计单局遭遇次数 | 若 > 25 次 → 遭遇过密，降低密度 |
| 守卫三阶段复杂度 | 三阶段 | 观察玩家在守卫战失败率 | 若 > 70% 失败 → 减少阶段或降低 AOE 范围 |

## 16. 术语表
